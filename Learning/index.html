Від Junior до Middle

.NET Backend · на прикладі TaroSideAI

Жива книга, зібрана навколо твого власного проєкту. Кожен приклад коду — з твоїх файлів, і кожен нетривіальний факт у ній перевірений компіляцією чи запуском, а не переказаний з пам'яті. Порядок розділів іде не за красивою навчальною програмою, а за твоїми реальними слабкими місцями — щоб найдорожчий для співбесіди матеріал ти отримав першим.

.NET 9 · C# 13 Clean Architecture EF Core + PostgreSQL JWT + Identity LLM Function Calling React + Vite
Автор проєкту: Максим Палій
Підготовлено як персональний навчальний довідник
📌 Як побудована ця книга Розділи 1–6 — це рівно ті шість слабких місць, які ти сам назвав: function calling, JWT, тестування, CI/CD, Azure, LLM під капотом. Кожен написаний за принципом ЧОМУ → ЯК → КОД, з мінімальним прикладом з нуля, розбором твого реального файлу, і завданням «відтвори сам» наприкінці. Розділи нижче ("резерв") — це поглиблення архітектури проєкту загалом; вони чекають своєї черги, коли пріоритетні шість будуть закриті.

Пріоритетні розділи — твої реальні слабкі місця, у цьому порядку
01

AI та Function / Tool Calling

Microsoft.Extensions.AI, IChatClient, AIFunctionFactory. Повний HTTP-обмін, JSON Schema, розбір ChatAiService.cs.

✦
02

JWT та ASP.NET Identity

Анатомія токена побайтово, HMAC-SHA256, повний pipeline логін→claims→User.FindFirstValue, розбір Program.cs + TokenService.cs, IDOR у ConversationsController.

✦
03

Тестування — з нуля

Unit vs integration, xUnit + Moq на реальному CardService/ConversationService, WebApplicationFactory, перші 10 тестів.

✦
04

CI/CD та Azure DevOps

Анатомія пайплайну, реальний ci.yml для твого solution, azure-pipelines.yml поруч, Docker vs App Service.

✦
05

Azure / хмара

App Service vs Functions vs Container Apps vs AKS, Postgres Flexible Server, Key Vault, Service Bus, App Insights, реальний деплой TaroSideAI.

✦
06

Як насправді влаштовані LLM

Ваги vs embeddings vs векторні БД, токенізація (реальні цифри UK/EN), attention, RAG на pgvector, безпека.
